# Guide joueur

Ce guide vous accompagne dans l'utilisation de l'application Dawn GN en tant que joueur.

## Première connexion

### Inscription

1. Accédez à la page d'inscription (`/register`)
2. Remplissez le formulaire :
   - Nom et prénom
   - Email (sera votre identifiant)
   - Mot de passe
   - Téléphone
   - Réseaux sociaux (optionnel)
3. Cliquez sur "S'inscrire"
4. Vous recevrez un email de confirmation

### Connexion

1. Accédez à la page de connexion (`/login`)
2. Entrez votre email et mot de passe
3. Vous serez redirigé vers votre tableau de bord

## Gestion du profil

### Modifier vos informations

1. Cliquez sur "Mon compte" dans le menu
2. Modifiez vos informations :
   - Nom, prénom
   - Téléphone
   - Réseaux sociaux
   - Droit à l'image
3. Cliquez sur "Enregistrer"

### Contacts d'urgence

1. Dans "Mon compte", section "Contacts d'urgence"
2. Cliquez sur "Ajouter un contact"
3. Remplissez :
   - Nom du contact
   - Téléphone
   - Relation (parent, ami, etc.)
4. Cliquez sur "Enregistrer"

### Allergies

1. Dans "Mon compte", section "Allergies"
2. Cliquez sur "Ajouter une allergie"
3. Indiquez :
   - Nom de l'allergie
   - Description (sévérité, traitement, etc.)
4. Cliquez sur "Enregistrer"

### Notes personnelles

1. Dans "Mon compte", section "Notes"
2. Cliquez sur "Ajouter une note"
3. Rédigez votre note
4. Cliquez sur "Enregistrer"

## Création d'un personnage

### Étape 1 : Création initiale

1. Cliquez sur "Mes personnages" dans le menu
2. Cliquez sur "Créer un personnage"
3. Remplissez les informations de base :
   - **Nom du personnage**
   - **Faction** : Choisissez parmi Nomads, Tech'ers, Rodoir, Néo-cuba
   - **Classe** : La liste des classes dépend de la faction choisie
4. Cliquez sur "Créer"

Le personnage est créé en mode **Brouillon** avec 30 XP de départ (20 XP Skills + 10 XP Gear).

### Étape 2 : Rédaction du background

1. Dans la page d'édition du personnage, section "Background"
2. Rédigez l'histoire et le background de votre personnage
3. Cliquez sur "Enregistrer"

### Étape 3 : Ajout de compétences

1. Section "Compétences" de votre personnage
2. Cliquez sur "Ajouter une compétence"
3. Consultez le catalogue de compétences disponibles
4. Vérifiez les prérequis (classe, faction, autres compétences)
5. Sélectionnez une compétence
6. Le coût en XP Skills s'affiche
7. Vérifiez que vous avez assez d'XP Skills disponibles
8. Ajoutez une note personnelle si vous le souhaitez
9. Cliquez sur "Ajouter"

**Astuce** : Les compétences peuvent avoir des prérequis. Vérifiez bien avant d'ajouter une compétence.

### Étape 4 : Ajout d'équipements

1. Section "Équipements" de votre personnage
2. Cliquez sur "Ajouter un équipement"
3. Consultez le catalogue d'équipements disponibles
4. Sélectionnez un équipement
5. Le coût en XP Gear s'affiche
6. Vérifiez que vous avez assez d'XP Gear disponibles
7. Ajoutez une note personnelle si vous le souhaitez
8. Cliquez sur "Ajouter"

### Étape 5 : Ajout d'assets

1. Section "Assets" de votre personnage
2. Cliquez sur "Ajouter un asset"
3. Les assets sont gratuits (coût 0 XP)
4. Sélectionnez un asset (capacité ou objet)
5. Pour les objets, indiquez la quantité
6. Cliquez sur "Ajouter"

### Étape 6 : Vérification et soumission

1. Vérifiez que vous avez utilisé vos XP de manière optimale
2. Relisez votre background
3. Vérifiez que toutes les informations sont correctes
4. Cliquez sur "Soumettre pour validation"

Le statut de votre personnage passe à **"En cours de validation"**.

## Gestion des XP

### Comprendre les XP

- **XP disponibles** : Total d'XP que vous pouvez encore dépenser
- **XP Skills** : Points alloués aux compétences
- **XP Gear** : Points alloués aux équipements

### Gagner des XP

Vous gagnez **3 XP** automatiquement après avoir participé à un événement Dawn terminé. Ces XP sont ajoutés à votre personnage principal.

### Répartir les XP

Lors de la création, vous recevez :
- 20 XP Skills (pour les compétences)
- 10 XP Gear (pour les équipements)

Vous pouvez ajuster cette répartition si nécessaire.

## Inscription à un événement

1. Dans "Mon compte", section "Inscriptions"
2. Cliquez sur "Ajouter une inscription"
3. Sélectionnez un événement Dawn disponible
4. Entrez votre numéro de ticket HelloAsso
5. Cliquez sur "Enregistrer"

**Note** : Après la fin de l'événement, vous recevrez automatiquement 3 XP sur votre personnage principal.

## Génération de la fiche de personnage

1. Dans la page d'un personnage validé
2. Cliquez sur "Générer la fiche PDF"
3. La fiche complète sera générée avec :
   - Informations du personnage
   - Compétences apprises
   - Équipements et possessions
   - Assets spéciaux
   - Background
   - Statistiques (PV max, armure, etc.)

## Statuts de validation

Votre personnage peut avoir différents statuts :

- **Non validé** : Personnage en cours de création (brouillon)
- **En cours de validation** : Soumis et en attente de validation
- **Validé** : Approuvé par un organisateur
- **Rejeté** : Refusé avec commentaires

Si votre personnage est rejeté, vous pouvez le modifier et le soumettre à nouveau.

## Conseils

1. **Prenez votre temps** : Créez votre personnage progressivement
2. **Lisez les descriptions** : Les compétences et équipements ont des descriptions détaillées
3. **Vérifiez les prérequis** : Assurez-vous de respecter les prérequis avant d'ajouter des éléments
4. **Gérez vos XP** : Planifiez l'utilisation de vos XP avant de les dépenser
5. **Rédigez un bon background** : Un background détaillé aide les organisateurs à valider votre personnage
